# 内容质量检查规则集

> 用于 Step 2 检查点，校验文案是否符合小红书平台要求。

## 强制规则（P0 — 违反即阻断）

| ID | 规则 | 校验方式 |
|----|------|---------|
| R1 | 必须包含 `#AI生成内容` 标签 | 文本搜索 |
| R2 | 标题长度 ≤ 20 字 | 字数统计 |
| R3 | 正文 300-600 字 | 字数统计 |
| R4 | 标签数量 5-8 个 | 计数 |
| R5 | 无敏感词/违禁词 | 词库匹配 |

## 建议规则（P1 — 违反时警告）

| ID | 规则 | 校验方式 |
|----|------|---------|
| R6 | 标题前 13 字含核心关键词 | 关键词匹配 |
| R7 | 正文以短句为主（单句 ≤ 30 字） | 句长统计 |
| R8 | 含 emoji 增强可读性（3-8 个） | 计数 |
| R9 | 首段 hook（疑问/数字/冲突） | 模式匹配 |
| R10 | CES 评分 ≥ 25/40 | xhs-content-creator 输出 |

## 违规处理

| 规则级别 | 处理方式 |
|---------|---------|
| P0 违反 | 自动修正 → 重新校验（最多 2 次）→ 仍失败则阻断并报告 |
| P1 违反 | 输出警告，不阻断，建议用户手动优化 |

## 自动修正策略

| 违规项 | 修正动作 |
|--------|---------|
| 缺少 AI 标签 | 在标签列表末尾追加 `#AI生成内容` |
| 标题超长 | 截取前 20 字并保留语义完整性 |
| 正文不足 300 字 | 调用 xhs-content-creator 扩写 |
| 正文超 600 字 | 调用 xhs 精简 |
| 标签不足 | 调用 xhs 推荐补充标签 |
| 标签过多 | 保留热度最高的 8 个 |
